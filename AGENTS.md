# Agents Guide

This file provides guidance for AI coding assistants working in this repository.

## Zyte Deploy Platform

This repository is deployed via the [Zyte Apps Deploy Platform](https://zadp.zyte.group).

Deployment is configured through `zyte-deploy.md` in the repository root. Edit that file to change replicas, resources, health checks, GCP services, auto-deploy branches, and access rules.

Full contract reference: https://zadp.zyte.group/public/contract
